# 小程序设计说明 · 常识急诊室

> 一句话定位：一个"中国人都以为是真的，其实不一定对"的常见误区档案馆。
> 用冷静、克制、有设计感的方式，把错误常识做成可翻卡、可答题、可收藏、可分享的科普小程序。

## 一、产品设计说明

**解决的问题**：大学新生（及大众）普遍被"从小听到大"的错误常识包围：家族群的养生偏方、校园里的过来人经验、想当然的物理常识。现有辟谣内容零散、看完即忘、缺乏系统感。

**产品隐喻**：一间安静的"档案馆 + 急诊室"。每条误区是一份编号卷宗（档案 NO.001），用户像在博物馆看展签一样翻阅；判断题玩法叫"拆弹"——每答对一题，拆掉一颗"常识哑弹"。

**信息架构**（底部 4 个 Tab + 1 个详情页）：

| 页面 | 定位 | 关键内容 |
| --- | --- | --- |
| 首页「今日反转」 | 每日入口 | 今日翻转大卡（按日期稳定生成）+ 今日三连问 + 最近收录 + 拆弹入口 |
| 档案馆「误区档案」 | 全量浏览 | 分类筛选（横向标签）、关键词搜索、按误区指数/编号排序、左滑/长按收藏、分批渲染 |
| 答题「拆弹挑战」 | 互动玩法 | 随机 5 题判断（一半"流传说法"答"讹"、一半"真相结论"答"真"），答错用"原来如此"式解释，成绩单 + 分享 |
| 我的「我的档案」 | 个人沉淀 | 收藏列表、答题统计、关于与免责声明、清除本地数据 |
| 详情页 | 完整卷宗 | 流传版本（盖"讹"章）→ 轻触翻面看真相 → 为什么错（编号要点）→ 适用条件 → 权威来源 → 收藏/分享 → 相关误区 3 条 |

**防偷懒设计**：40 条全是误区，若判断题永远答"讹"就失去挑战性。因此拆弹题双题型交替：展示流传说法（答"讹"）与展示真相结论（答"真"），直觉无法蒙对。

## 二、视觉 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| 纸白 | `#F7F3EA` | 全局背景（page / 导航栏 / tabBar） |
| 卡片纸 | `#FBF9F3` | 卡片底色 |
| 墨黑 | `#1F1F1D` | 正文 / 真相卡反面底色 |
| 朱红 | `#C33A2E` | 选中态 / "讹"章 / 强调 |
| 暖灰 | `#8A857C` | 次要文字 / 标签 |
| 细线 | `#D9D2C3` | 边框 / 分割线 / 占位 |

**字体**：大标题、档案编号用系统 serif（Georgia / Songti SC）；正文系统无衬线。标题 48-64rpx，正文 30-32rpx，行高 1.7。

**网格与形状**：8pt 网格；页面左右 40rpx；卡片圆角 16rpx；阴影 `0 2rpx 8rpx rgba(31,31,29,0.04)`（极克制）。

**动效**：翻牌 320ms `cubic-bezier(0.25,0.8,0.35,1)`；列表进入 fadeUp 320ms（轻微上浮）；无弹跳、无彩虹渐变、无震惊体、无低质 emoji。

**档案元素**：档案编号（NO.001，serif）、细分割线、"讹"字朱红斜章（rotate(-6deg)）、误区指数 5 点刻度、分类标签章。

## 四、内容分类与 40 条清单

五大科室 × 各 8 条（误区指数 ★ 越多流传越广）：

- **饮食健康**：骨头汤补钙、菠菜补铁、隔夜菜致癌、白粥养胃、果汁=水果、趁热吃、无糖饮料随便喝、红糖补血
- **校园生活**：不挂科不完整、熬夜修仙、考前突击、插线板串接、刷单兼职、社团越多越好、四六级裸考、充电常驻插座
- **生活物理**：公牛见红色、高铁辐射、微波炉致癌、电梯下坠起跳、水池漩涡南北半球、雷雨天玩手机、电池用完再充、湿发感冒
- **动物植物**：金鱼 7 秒记忆、鸵鸟埋沙、蝙蝠是瞎子、仙人掌防辐射、北极熊白毛、鲨鱼不患癌、驼峰储水、竹子是树
- **历史文化**：拿破仑矮、爱因斯坦不及格、长城太空可见、哥伦布证明地圆、牛顿被苹果砸、埃及艳后是埃及人、空城计原创、七月流火

完整逐条清单（含误区指数）见 `docs/数据索引.md`；结构化数据见 `miniapp/utils/data.js`（同源派生自 `data/myths.json`）。

## 五、运行说明

1. 打开微信开发者工具 → 导入项目 → 选择 `miniapp/` 目录；
2. AppID 选择"测试号"（已内置 `touristappid`），或替换为你自己的 AppID；
3. 基础库版本 ≥ 2.33.0；
4. 编译运行即可，无后端、无网络请求、无外部图片依赖。
