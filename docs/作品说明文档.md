# 作品说明文档

**作品名称**：常识急诊室——大学生防忽悠与反常识档案馆
**作品形态**：WorkBuddy 技能（Skill）
**参赛信息**：大连民族大学 ______学院 ______级____班 ______（姓名/学号，提交前请填写）

## 一、真实问题

大学新生刚脱离家庭与中学的信息环境，就立即暴露在更复杂的网络信息流中：家族群里的养生偏方、短视频平台的伪科学、校园里口口相传的"过来人经验"，在无人纠偏的情况下被当作常识长期留存。新生正处在独立生活决策最密集的阶段——吃什么、怎么用电、找什么兼职、如何备考，每一项都可能被"想当然"误导并造成实际损失。现有辟谣内容多为零散文章，看完即忘，缺乏系统化、可交互、可复用的知识服务。

## 二、创意思路

作品把枯燥的辟谣科普转化为「知识档案」体验：每则流传说法都是一份编号卷宗，包含流传说法、真相结论、为什么错、适用条件、权威来源、误区指数（1-5星）与一句档案批注——风格克制、来源可查，像一间安静的档案馆而非标题党。智能体化身"常识急诊室值班主任"，提供五种玩法：急诊挂号（说法验证）、今日翻牌（先猜后看）、分类巡诊（五大科室浏览）、拆弹挑战（五题常识小测，答错不嘲笑）与科普二次创作。把"你相信的未必是真的"变成一场可分享的智力游戏，兼顾趣味性与分享欲。

## 三、操作流程（AI 赋能）

作品全程与 WorkBuddy 人机共创：第一步，用自然语言向 WorkBuddy 描述赛道定位与产品框架，由它完成需求拆解、信息架构与卷宗字段设计；第二步，让 WorkBuddy 批量起草 40 条误区数据，我逐条人工复核，要求每条给出权威出处，凡无法核实的内容一律删除或改写为审慎表述，并确立"不绝对化、未收录不编造依据、涉医提示遵医嘱"三条红线；第三步，由 WorkBuddy 生成技能说明文件 SKILL.md，把五种玩法与值班纪律固化为可执行工作流；第四步，持续用自然语言指令迭代文案、批注风格与演示脚本。AI 负责生成与初筛，人负责事实把关与体验取舍，全程可复现。

## 四、应用效果

作品为纯本地数据的 WorkBuddy 技能，无需后端与密钥，复制到技能目录即可加载运行，可复现性强；内容横跨传播学（谣言扩散机制）、计算机（技能工程）与科学素养（证据分级与来源意识），体现跨学科思维；"校园生活"科室直接服务新生防骗、用电与备考安全。数据与结构完全解耦，任何高校替换校园条目即可本地化推广，具备向全国高校复制的潜力。
