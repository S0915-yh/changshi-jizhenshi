## 五、验收标准（需求方原始条款）

1. **导入无编译错误**：所有 JS `node --check` 通过；所有 JSON 严格解析通过（app.json 已去注释）；工程级脚本校验页面注册、tabBar 路径、组件引用、事件处理器全对齐。剩余风险：3D 翻面依赖 WebView 的 `backface-visibility`，主流机型均支持。
2. **4 个 Tab + 详情页可点通**：tabBar 四页 + 详情页 `wx.navigateTo` 跳转链路完整（首页/档案馆/相关误区/收藏均可进详情）。
3. **翻卡/筛选/搜索/答题/收藏/分享可用**：均有实现与数据通路；分享用 `onShareAppMessage` + `open-type="share"`。
4. **至少 40 条、分类完整、来源明确、无敏感**：✅（40 条、5 科室各 8、来源全真实可查）。
5. **第一眼像知识档案馆**：纸感底色 + 档案编号 + 展签排版 + serif 标题。
6. **无土味元素**：✅。
7. **代码有注释不啰嗦、命名规范**：文件头一段式注释 + 关键段落短注。
8. **完整文件内容与运行说明**：见 `docs/小程序设计说明.md` 第五节。
